📚 DAA Question Paper Generator

An intelligent Question Paper Generator developed using **Java** and the **0/1 Knapsack Algorithm** to automatically generate balanced examination papers based on marks distribution and selected topics.

## 🚀 Features

- Teacher Mode (Exact Marks using Dynamic Programming)
- Student Mode (Randomized Practice Papers)
- 0/1 Knapsack Algorithm Implementation
- CSV-Based Question Bank
- Question Analytics Dashboard
- Add Questions at Runtime
- Export Generated Papers
- Interactive HTML Dashboard
- Modular Java Architecture

## 🛠 Tech Stack

- Java
- HTML
- CSS
- JavaScript
- CSV File Handling
- Dynamic Programming
- Data Structures & Algorithms

## Topics Covered

- Arrays
