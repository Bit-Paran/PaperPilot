Knapsack Algorithm
How it works:
① Build a boolean DP table dp[i][w]
② dp[i][w] = true if first i items sum to exactly w
③ Backtrack to find which questions were selected
④ Shuffle selected set to randomise order
Complexity: O(n × W) time, O(n × W) space
